# My Portfolio

A portfolio website built to look and feel like a VS Code editor, live at [giovannileo.vercel.app](https://giovannileo.vercel.app).

Instead of a traditional single-page layout, the site mimics the VS Code interface: file explorer sidebar, tabs, editor panels powered by [Monaco Editor](https://microsoft.github.io/monaco-editor/), an integrated terminal, and a command palette — all interactive. It's a fun way to present my experience, projects, and skills as a developer.

## Tech Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Monaco Editor
- React Router
- Zustand
- TanStack Query + Axios (live GitHub data)
- react-markdown

## Getting Started

```bash
npm install
npm run dev
```

Build and preview:

```bash
npm run build
npm run preview
```

## Deploy

Hosted on Vercel (see `vercel.json`).
